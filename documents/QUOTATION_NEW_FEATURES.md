# คู่มือฟีเจอร์ใหม่ในใบเสนอราคา

## ฟีเจอร์ที่เพิ่มใหม่

### 1. ระยะเวลาที่ยื่น (Delivery Time)
- ช่องกรอกระยะเวลาในการส่งมอบสินค้า/บริการ
- ตัวอย่าง: "5-7 วัน", "2 สัปดาห์", "1 เดือน"
- แสดงในใบเสนอราคาเมื่อพิมพ์/ส่งออก PDF

### 2. เงื่อนไขการชำระเงิน (Payment Terms)
- มีระบบเทมเพลตสำหรับเงื่อนไขการชำระเงินที่ใช้บ่อย
- สามารถสร้าง/แก้ไข/ลบเทมเพลตได้
- เลือกเทมเพลตแล้วข้อความจะถูกเติมใน textarea อัตโนมัติ
- สามารถเพิ่มข้อความเองหรือแก้ไขได้

**เทมเพลตเริ่มต้น:**
- โอนเงินล่วงหน้า 100%
- มัดจำ 50%
- เครดิต 7 วัน
- เครดิต 30 วัน

### 3. หมายเหตุแบบเทมเพลต (Notes Templates)
- มีระบบเทมเพลตสำหรับหมายเหตุที่ใช้บ่อย
- สามารถสร้าง/แก้ไข/ลบเทมเพลตได้
- เลือกเทมเพลตแล้วข้อความจะถูกเติมใน textarea อัตโนมัติ
- สามารถเลือกหลายเทมเพลตรวมกันได้

**เทมเพลตเริ่มต้น:**
- การรับประกัน
- การจัดส่ง
- ราคาพิเศษ

### 4. QR Code สำหรับชำระเงิน
- อัพโหลดรูป QR Code สำหรับการชำระเงิน
- แสดงใต้หมายเหตุในใบเสนอราคา
- แสดงทั้งในการพิมพ์และ PDF

## วิธีการใช้งาน

### การจัดการเทมเพลต

#### สร้างเทมเพลตใหม่:
1. คลิกปุ่ม "⚙️ จัดการเทมเพลต" ข้างช่องเงื่อนไขการชำระหรือหมายเหตุ
2. คลิก "+ เพิ่มเทมเพลตใหม่"
3. กรอกชื่อเทมเพลตและเนื้อหา
4. คลิก "บันทึก"

#### แก้ไขเทมเพลต:
1. เปิดหน้าจัดการเทมเพลต
2. คลิก "แก้ไข" ที่เทมเพลตที่ต้องการ
3. แก้ไขข้อมูล
4. คลิก "บันทึก"

#### ลบเทมเพลต:
1. เปิดหน้าจัดการเทมเพลต
2. คลิก "ลบ" ที่เทมเพลตที่ต้องการ
3. ยืนยันการลบ

### การใช้เทมเพลต

#### เงื่อนไขการชำระเงิน:
1. เลือกเทมเพลตจาก dropdown
2. ข้อความจะถูกเติมใน textarea
3. สามารถแก้ไขข้อความเพิ่มเติมได้
4. เลือกเทมเพลตหลายอันได้ (จะต่อท้ายกัน)

#### หมายเหตุ:
1. เลือกเทมเพลตจาก dropdown
2. ข้อความจะถูกเติมใน textarea
3. สามารถแก้ไขข้อความเพิ่มเติมได้
4. เลือกเทมเพลตหลายอันได้ (จะต่อท้ายกัน)

### การอัพโหลด QR Code

1. คลิกปุ่ม "เลือกไฟล์" ในช่อง QR Code
2. เลือกรูป QR Code จากคอมพิวเตอร์
3. ตัวอย่างจะแสดงทันที
4. QR Code จะถูกบันทึกพร้อมกับใบเสนอราคา

## การติดตั้ง

### 1. สร้างตารางและคอลัมน์ใหม่
```bash
php create_quotation_templates.php
```

สคริปต์นี้จะ:
- สร้างตาราง `quotation_templates` สำหรับเก็บเทมเพลต
- เพิ่มคอลัมน์ `delivery_time`, `payment_terms`, `qr_code_image` ในตาราง `quotations`
- สร้างเทมเพลตเริ่มต้น

### 2. ตรวจสอบไฟล์ที่เกี่ยวข้อง
- `quotation_form.php` - ฟอร์มสร้าง/แก้ไขใบเสนอราคา (อัพเดทแล้ว)
- `quotation_action.php` - API สำหรับบันทึกข้อมูล (อัพเดทแล้ว)
- `template_action.php` - API สำหรับจัดการเทมเพลต (ไฟล์ใหม่)
- `create_quotation_templates.php` - สคริปต์สร้างตาราง (ไฟล์ใหม่)

## โครงสร้างฐานข้อมูล

### ตาราง quotation_templates
```sql
- id (INT, PRIMARY KEY, AUTO_INCREMENT)
- company_id (INT) - รหัสบริษัท
- template_type (ENUM: 'payment_terms', 'notes') - ประเภทเทมเพลต
- template_name (VARCHAR) - ชื่อเทมเพลต
- template_content (TEXT) - เนื้อหาเทมเพลต
- created_at (DATETIME)
- updated_at (DATETIME)
```

### คอลัมน์ใหม่ในตาราง quotations
```sql
- delivery_time (VARCHAR) - ระยะเวลาที่ยื่น
- payment_terms (TEXT) - เงื่อนไขการชำระเงิน
- qr_code_image (TEXT) - รูป QR Code (base64)
```

## หมายเหตุสำหรับ PDF

⚠️ **ปัญหาที่ทราบ:** 
- การ export PDF อาจไม่แสดงรูปภาพ QR Code ได้ถูกต้อง 100%
- แนะนำให้ใช้การพิมพ์แทน (Print to PDF จากเบราว์เซอร์)
- กำลังพัฒนาแก้ไขปัญหานี้

## Tips & Tricks

1. **เทมเพลตที่ดี:** สร้างเทมเพลตสำหรับเงื่อนไขที่ใช้บ่อย เพื่อประหยัดเวลา
2. **QR Code:** ใช้รูป QR Code ที่มีความละเอียดสูงเพื่อความชัดเจน
3. **หมายเหตุ:** สามารถใช้หลายเทมเพลตรวมกันได้ โดยเลือกทีละอัน
4. **ระยะเวลา:** ระบุระยะเวลาที่ชัดเจน เช่น "5-7 วันทำการ" แทน "เร็วๆ นี้"

## การแก้ไขปัญหา

### เทมเพลตไม่แสดง
- ตรวจสอบว่ารันไฟล์ `create_quotation_templates.php` แล้ว
- ตรวจสอบว่าตาราง `quotation_templates` ถูกสร้างแล้ว

### QR Code ไม่แสดง
- ตรวจสอบว่าอัพโหลดรูปภาพแล้ว
- ตรวจสอบว่ารูปภาพเป็นไฟล์ที่ถูกต้อง (JPG, PNG)
- ตรวจสอบขนาดไฟล์ไม่ใหญ่เกินไป

### ข้อมูลไม่บันทึก
- ตรวจสอบว่าคอลัมน์ใหม่ถูกเพิ่มในตาราง `quotations` แล้ว
- ตรวจสอบ Console ในเบราว์เซอร์หา error
